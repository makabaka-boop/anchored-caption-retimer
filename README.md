# 字幕固定与重叠消除（cue-lock）

纪录片补录后，字幕编辑员需要锁定少数字幕的起点并消除相邻重叠。本工具以
**已采纳稿**为基线，求解满足约束的新起点向量，并标记每条 cue 的位移。

## 约束与目标

对 cue `i`（0 基）设新起点为 `x_i`，已采纳稿起点为 `b_i`，时长为 `d_i`：

1. 固定点精确命中：被锁定的 cue 满足 `x_i = v`；每个 cue 最多一个固定点，
   重复编辑覆盖旧值，删除即解除；
2. 全天边界：`0 ≤ x_i ≤ 86 400 000`；
3. 相邻不重叠：`x_{i+1} ≥ x_i + d_i`；
4. 最小化总位移 `Σ |x_i − b_i|`；
5. 多个最优解时，取按 cue 顺序**字典序最小**的整数向量。

### 算法

作变量代换 `z_i = x_i − Σ_{j<i} d_j`，非重叠约束变为保序约束，问题成为带
逐点区间与固定点的整数 **L1 保序回归**。使用斜率技巧（左大根堆/右小根堆的
PAVA）逐列扫描，O(n log n) 求解；反向贪心 `z_i = min(s_i, z_{i+1})` 重建
分量最小（即字典序最小）的最优向量。20 000 项实测约 20 ms。

## 导入与错误

- 导入 JSON 根对象**仅含** `cues`（1–20000 项），每项**仅含**整数
  `start`（0–86 400 000，严格递增）、`duration`（1–60 000）和
  `text`（长 1–200）。
- 非法导入显示 **INVALID_CUES**，清空旧预览，但保留最近合法工作稿。
- 约束不可行（固定点互相冲突、被挤出全天、总时长超过全天等）显示
  **INFEASIBLE**，并清空旧预览。

## 操作

- **生成预览**：求解并显示新起点与每条位移（未位移不标记）；
- **采纳**：把当前预览作为下一轮基线（位移标记归零，固定点保留）；
- **下载同结构 JSON**：导出当前已采纳稿，`duration`/`text` 原样保留。

## 开发

```bash
npm ci
npm run dev       # 本地开发
npm run verify    # 类型检查 + 生产构建 + 全部 Vitest（一次性验收）
```

测试含短序列（1–4 项）随机穷举 400 例，逐案核对最优目标值与完整向量，
并显式覆盖偶数块平局与固定点临界冲突；另有 20 000 项性能断言（< 2000 ms）。

## Docker Compose

```bash
cp .env.example .env      # 按需修改 WEB_PORT
docker compose up -d web  # 以 ${WEB_PORT} 发布页面
docker compose --profile verify run --rm verify   # 一次性验收（跑完即退出）
```
